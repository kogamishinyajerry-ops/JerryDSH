01第一性原理：六条公理

每条公理都是一个可独立验证的物理事实（不是观点）。整栋方法论大厦从这里推导： 公理 → 禁止什么 / 要求什么 → 失败模式 → 技巧。只要这六条事实不变，技巧就永远有效；模型换代变了哪条，就重推哪条。 这就是第一性原理的价值——你不需要背任何一条技巧。

公理二的直接后果：注意力预算按 token 封顶，质量在窗口上限之前就开始衰减——「越用越笨」不是 bug，是物理。

02主流五步：idea → ship 的次序为什么不可换

次序本身就是防错机制：拷问在 spec 前（先消灭猜测）、spec 在实现前（先外化记忆）、审查在提交前（独立验证）。 换掉次序，每一步本来防住的失败模式就会回来。DSH 里对应 eng-idea-to-ship（用户入口技能）编排以下五步。

1拷问对齐 · eng-grilling

治「做出来的不是要的」——misalignment 是 AI 协作第一大失败模式
怎么用 开工前说「拷问我这个想法 / grill me」。agent 把需求建成设计树，按轮次问完整个前沿（前置已定、现在就能问的问题），每题编号并附推荐答案；你答完它重算前沿再问下一轮。
学精髓 两条铁律内化：事实是 agent 的活（能查的绝不问你，探索不阻塞提问）、决策是你的活（每个决策摆给你等）。前沿为空 + 你确认共识，才准动手。
第一性 公理三：模型对未知静默填空，猜与选不可分辨。两行提示直接要产出＝把设计权交给默认值。拷问是把「猜」变回「问」的唯一通道。

2原型支线 · prototype

治「要看一眼才知道」——对话分辨率不够的问题
怎么用 拷问中撞到纸面定不了的问题（状态机手感 / UI 长相）就分叉：造一次性原型只回答这一个问题——逻辑问题→单文件 HTML 自由操作台（纯模块可整体抬回真代码）；UI 问题→同路由 ?variant= 多变体切换。
学精髓 原型是用完即弃的提问方式：不测试、不抽象、内存态、跑起来就行。结论折回真代码，原型本身提交到 prototype/<name> 分支当一手来源。
第一性 公理四：有些知识只存在于运行中。可运行物是人类与模型之间分辨率最高的沟通语言。

3固化 · to-spec + to-tickets

治「决策随会话蒸发」——会话可弃，交接物长存
怎么用 拷问共识说「落成 spec 和工单」。不重新访谈，只合成：spec 按模板（Problem / Solution / 用户故事 / 实现决策 / 测试决策 / Out of Scope），写前先和你确认测试 seam；工单＝曳光弹垂直切片（每片穿透所有层、独立可演示、一个 smart zone 装得下）+ 阻塞边。宽改造走 expand–contract：先并存新形态，分批迁移，最后删旧。
学精髓 spec 和工单是无状态模型的记忆假肢。每张票自足到可以被一个全新会话捡起——这不是官僚手续，是让「会话可弃」成为安全的架构决策。
第一性 公理一：会话清零。一切跨会话价值必须外化为环境文件；不外化的决策等价于没做过。

4实现 · implement × eng-tdd

治「无反馈乱飞」——反馈速率是速度上限
怎么用 每张票开新会话实现。驱动 eng-tdd：先写下要测的 seam 清单并确认（未经确认的 seam 上一条测试都不写），然后 red→green：写一个失败测试 → 恰好让它通过的实现 → 下一片。类型检查常跑、全量测试收尾跑一次。
学精髓 三个反模式要认得出：实现耦合（重构就红）、同义反复（断言用实现的方式重算期望值，构造上必过）、水平切片（先写完所有测试再写实现＝验证想象）。期望值必须来自独立真值。
第一性 公理四+六：模型只见窗口且非确定。窗口里没有独立真值时，模型会自信地漂移——失败测试是唯一便宜、快速、可重复的真值注入。

5审查 · eng-code-review

治「谄媚审查」——验证者必须与生产者隔离
怎么用 implement 收尾自动跑：钉住固定点取 diff，两个并行子代理分跑两轴——Standards（仓库成文规范 + 12 条 Fowler smell 基线）与 Spec（是否忠实实现来源 issue：缺失 / 超范围 / 做错）——报告并排呈现，不合并排序。
学精髓 一份改动可以过一轴挂另一轴：规范全对但做错了东西，或做对了但破坏约定。分开报告是防止一轴掩盖另一轴；「看起来不错」不是审查。
第一性 公理三+六：附和倾向 + 非确定 ⇒ 自己审自己必然漏。并行子代理＝验证者上下文与生产者上下文物理隔离。
拷问的设计树：绿色＝已定决策，红虚线＝开放，蓝＝前沿（前置已定、现在就能问的）。答案重塑树，前沿外推，直到为空。
TDD 循环：红→绿→下一片。循环小到可笑才对——「一次一片」不是教条，是让每一片都吃到上一片的教训。
双轴审查：一份改动可以过一轴挂另一轴——并排呈现防止「规范全对但做错了东西」被「代码很整洁」掩盖。

03四根支柱：跑在主流下面的纪律与词汇

主流回答「按什么次序做」，支柱回答「用什么语言说、按什么标准看」。四个技能都是模型可调用——任务匹配时 agent 自动加载。

eng-domain-modeling · 共享语言

语言是注意力的压缩器
怎么用 讨论中术语一结晶就写进 CONTEXT.md（词汇表：术语＋一两句定义＋Avoid 列表）；难逆决策过三条件（难逆 / 无上下文会费解 / 真实权衡）才记 ADR，一段话即可。
学精髓 词表冲突当场挑（「你说的 account 是 Customer 还是 User？」）；与代码交叉验证（「代码只支持整单取消，你说可以部分取消——哪个对？」）。CONTEXT.md 只是词汇表，绝不当 spec 用。
第一性 公理二：注意力按 token 封顶。「materialization cascade」一个词顶一句话——共享语言让同一预算装下更多工程，还让 agent 的命名/导航/思考全部对齐。

eng-codebase-design · 深模块

depth / seam / adapter / leverage / locality
怎么用 设计接口时用这套精确词汇（不漂移成「组件/service/API」）：深模块＝大量行为藏在小接口后。疑似浅模块过删除测试：删掉它，复杂度集中（好）还是只是搬家（坏）？
学精髓 深度是接口的属性不是实现的——内部可以由小块组成，只是不属接口。一个 adapter 是假想 seam，两个才是真 seam。
第一性 公理五：生成放大熵。深模块是唯一同时改善杠杆（调用方）、局部性（维护方）、可测性（所有人）的结构——把复杂度关回笼子。

eng-diagnosing-bugs · 诊断纪律

回路是 90%，其余是机械
怎么用 硬 bug 交给它，六阶段：①造会红的回路（一条已跑过、确定、秒级、agent 可跑、断言你的确切症状的命令）→②复现+最小化（每个残留元素 load-bearing）→③3–5 个可证伪排序假设（先给你看）→④单变量插桩（[DEBUG-xxxx] 标签）→⑤先写回归测试再修→⑥清理（grep 标签，胜出假设写进 commit）。
学精髓 「没有能红的命令，就没有假设阶段」——直接读代码建理论正是这个技能要防的失败。回路要当产品经营：更快、更锐、更确定。
第一性 公理四：模型会自信地编。二分、假设检验、插桩全都只是消费一个真值信号——信号本身必须先存在。

eng-writing-for-agents · 为 agent 写作

指针经济学：一行指针，按需千金
怎么用 写 AGENTS.md / 技能 / 任何指针文档时自动加载。核心杠杆：context pointer 措辞决定触发（触发词前置、一个分支一个触发）；信息三级阶梯（步骤断言＞文件内参考＞披露参考）；完成判据要可判且穷尽；用引导词（tight / red / frontier）招募模型先验；逐句猎 no-op。
学精髓 两种负载分开算：context load（常驻窗口，每轮付费）与 cognitive load（人的索引成本）。塞满的说明书让 agent 每件事都变差——注意力预算不陪你练勤奋。
第一性 公理二：每个常驻 token 双重计费（钱＋注意力）。渐进披露不是省钱技巧，是稀缺资源下的必然经济学。
深 vs 浅：depth 是接口的属性——调用方每学一单位接口能驱动的行为量。深＝杠杆＋局部性；浅＝调用方替你读实现。

04四个特种兵：按需启用

不日常，但各自的触发场景一旦出现，没有它们就要付数量级的代价。

上下文卫生 · 阶段边界

边界换挡，不在阶段中间劈
怎么用 阶段（拷问/实现/QA）之间的空隙上，按五问决策树自上而下：①本会话能继续吗（下一阶段需要本阶段做一手来源 / smart zone 还够）→②上下文对接下来无关吗（新会话）→③需要交接吗（新 harness / 新目录 / 同事 / 中途分叉）→④能 AFK 吗（子代理）→⑤否则压缩（带一句保留指引）。
学精髓 压缩是默认项不是第一反应——它垫底因为上面四问都更便宜或更精准；从压缩开始的人常得到「对被摘要拍扁的决策自信地错」的新会话。
第一性 公理二：衰减无报错无边界，只能在边界主动管理；Continue 以外每个动作都把一手来源变二手——先问「留下的代价」再付「有损的价」。

wayfinder · 迷雾工程

规划不是执行：产出决策，不是交付物
怎么用 工程大到装不下且路看不见时说「画张地图」：tracker 上一个 wayfinder:map 父 issue + 决策票子 issue（research/prototype/grilling/task 四型）。一会话一票（research 例外），解决→关票→地图 Decisions-so-far 加指针→迷雾毕业新票。雾散后并入主流 to-spec。
学精髓 雾还是票？检验是「能否现在精确陈述问题」，不是「能否现在回答」。想直接干活的冲动＝已到地图边缘，该移交主流。
第一性 公理一+三：大工程的未定决策远超一个会话——先花便宜的决策预算消灭不确定性，再花贵的实现预算。

eng-architecture-review · 架构巡检

本报告就是它的产物形态
怎么用 空档时说「巡检架构」：按 YAGNI 先定范围（git log 热点优先）→子代理走查找加深机会（删除测试过滤）→产出规格驱动、几何校验的可视化 HTML 报告（候选卡：Files / Problem / Solution / Benefits / Before-After 图 / Strong–Worth exploring–Speculative 徽章）→挑中一个带回拷问立项。
学精髓 巡检是盘点不是施工；agent 加速代码熵，这是每天投资设计的机制化。
第一性 公理五：熵不休假。加深是唯一让「未来变更」变便宜的杠杆；报告可验证，因为图和代码一样会腐烂。

eng-wizard · 人的关卡

世界有一半只有人能走进
怎么用 agent 撞上只有人能过的墙（开账号 / 拿密钥 / 走陌生控制台）时自动触发：先读 repo 列出每个 stage 及其产出的值（CI 里每个 secrets.* 引用都要有着落），确认后生成分步 bash 向导——开 URL→说要复制什么→ask_secret 隐藏输入→幂等写 .env/gh secret→不可逆动作前 confirm。
学精髓 人机分工的接口工程：不编造可能不存在的步骤；不自己端到端跑（它等人输入）——静态走查每个值有着落即可。
第一性 公理四：环境有一半在 agent 感知之外。把人能走的路铺成可重走的台阶，把「每次重新解释」变成「跑一次脚本」。
阶段边界五问决策树：自上而下，第一个「是」获胜。压缩带一句保留指引（「接下来要 QA 这块」）让摘要留住下一阶段需要的东西。

06学习路径：三层进阶 + 四周练手

学习精髓总纲——三层进阶：
① 先学词（词汇即技术）：tight / red / frontier / tracer bullet / seam / deep module / expand–contract / fog of war / handoff artifact / context pointer——引导词直接锚定 agent 行为，你说「造个 tight 的回路」，它立刻知道要快、确定、锐利、可跑。检验：每个词能一句话讲给同事。
② 再学流（次序即防错）：拷问→spec→逐票→审查的次序换了，每步防的失败模式就回来。检验：能说出每一步防哪个失败模式、它来自哪条公理。
③ 后学判断（taste 层）：边界五问、雾还是票、seam 放哪、值不值得 TDD——没有机械答案，只有按序问的问题。按序问，就是判断力的全部训练法。
第 1 周 · 对齐

拷问 + wait-what

技能：eng-grilling
作业：拿一个真实小需求让 agent 拷问到前沿为空；数一数它问出了几个你没想过的决策。
第 2 周 · 交付

主流全流程

技能：eng-idea-to-ship（spec→tickets→逐票）
作业：跑一个小特性；spec 生成前亲手确认 seam 清单，再看它的 Testing Decisions 是否如约。
第 3 周 · 反馈

TDD + 诊断

技能：eng-tdd eng-diagnosing-bugs
作业：测试先行的造一个小功能；找一个真 bug 体验「没有能红的命令就没有假设阶段」被拦住的感觉。
第 4 周 · 设计

词汇 + 巡检

技能：eng-codebase-design eng-architecture-review
作业：巡检自己的 repo，找到一个过删除测试的加深机会，带回拷问立项。
持续层

按需启用

技能：eng-writing-for-agents（每次写 AGENTS.md/技能时）；wayfinder / eng-wizard（场景触发）；dsh-school（想学机制时）。
习惯：每次会话结束问自己——这次哪个失败模式差点发生、哪个技能救的场。

08可视化方法：Archify 产线（本报告怎么做的）

本报告的可视化对齐 tt-a1i/archify（可验证架构图，21.7k★）的核心约定：规格驱动 · 几何校验 · 多视图 · 主题化 · 零 CDN 自包含。 图不是画完就算——图和代码一样会腐烂，所以图也要有测试。

约定本报告的实现
规格驱动matt-pocock-dojo.architecture.json 是唯一真源：33 组件（id/type/label/pos/size）、39 连线（from/to/label/路由边）、5 视图（focus 子集）、13 张 cards。画布与速查表都由它渲染。
可验证validate-geometry.mjs 四道门：越界 / 两两重叠(8px) / 连线悬空引用 / 视图引用。本次真实抓到 f5→t-tdd 悬空引用并修复——校验不是仪式，真的咬人。产物 matt-pocock-dojo.visual-check.json：PASS。
多视图一张图五个镜头：全景 / 第一性原理 / 主流 / 纪律与词汇 / 特种兵。非焦点组件降透明度而不是删除——结构始终在场。
主题化 + 可分享暗/亮双主题（首绘前解析，无闪烁）；?view=mainflow&theme=light 直接分享某个镜头。
零 CDN 自包含双击即开、离线可用、邮件可发——报告是交付物，不是网页服务。
复用对任意代码库说「巡检架构」（DSH 技能 eng-architecture-review）即走同一产线：探索→候选→spec→校验→HTML 报告。
