## 五、下一轮实测 shortlist（推荐优先级）

1. **`dsh-pdf-reader`** —— vision 线补位，PDF 是工程+研究的硬需求；与我已测的 free-vision-skill（全本地 OCR）/modlens（VLM failover）正交，能凑齐"文档读入"三件套。
2. **`dsh-cron`（squirrel20）** —— 与已测 chicheng-cron 做横向对比（同为 agent 任务调度，combo3 刚证明 agent 任务价值），定哪个进晨报管线。
3. **`dsh-llm-approve-for-me`** —— 安全审批自动化，衔接 08-security-model 与 advisor，是"审批门控"从人到 LLM 的关键一步（注意：自动审批本身有风险面，测试时要重点验"隔离 LLM 是否真的隔离"）。
4. **`dsh-session-guard`** —— 成本/并发治理新面，与 usage-plugin 可组"用量+闸门"成本治理组合。

**观察不测**：桌面三件套 + dsh-web 聚合包（环境级大件，等生态收敛）；open-design/archify/distilly（跨 agent 技能，非 DSH bundle，接入方式不同）。
